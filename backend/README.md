# Flutter Backend

This repository contains the Laravel 11 backend API for the Flutter application.

## Overview

- Framework: Laravel 11
- Runtime: PHP 8.2
- API structure: RESTful JSON endpoints
- Backend root: `backend/`

## Project Layout

- `backend/app/` - application code
- `backend/config/` - configuration files
- `backend/database/` - migrations, seeders, factories
- `backend/routes/api.php` - API routes
- `backend/README.md` - project documentation

## Notes

This backend is organized to keep all Laravel application files under the `backend/` directory and to avoid maintaining duplicated root-level prefixed files.
