# Laravel Setup

## Requirements

- PHP 8.2
- Composer
- Laravel 11 compatible environment

## Installation

1. Install dependencies with Composer.
2. Configure environment variables in `.env`.
3. Generate the application key.
4. Run migrations and seeders as needed.

## Common Commands

- `php artisan migrate`
- `php artisan db:seed`
- `php artisan serve`

## Backend Location

All Laravel source files should live under `backend/`.
